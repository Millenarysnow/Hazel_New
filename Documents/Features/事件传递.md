# Hazel 事件处理和传递

## 流程
```
操作系统
   ↓
GLFW 负责创建窗口、接收键盘鼠标事件、创建 OpenGL Context
（引擎中注册了 GLFW 的按键回调）
   ↓
Hazel 把 GLFW 的东西包装成自己的 Window / Event / Input 系统
   ↓
ImGui 也从 GLFW/引擎那里得到输入，用来操作按钮、窗口、输入框
   ↓
OpenGL 负责渲染
   ↓
GLAD 只是拿到 OpenGL 函数入口
```

ImGui 和 引擎都从 GLFW 处拿到输入信息，因为是不同层在工作，同一份输入被不同层消费。  
为了避免同一份输入被处理多次，引擎中为事件添加了 Handled 字段。

## 对比
| 组件 | 作用 | 处理输入 | 直接渲染 |
| :---: | :---: | :---: | :---: |
| GLAD | 加载 OpenGL 函数 | ❌ | ❌ |
| GLFW | 创建窗口、OpenGL Context、接收系统输入 | ✅ | ❌ |
| OpenGL | 图形 API，负责画图 | ❌ | ✅ |
| Hazel Input/Event | 引擎自己的输入封装和事件分发 | ✅ | ❌ |
| ImGui	| GUI 系统，按钮/窗口/输入框等 | ✅ | ✅ |
| Hazel Renderer | 调 OpenGL 画场景 | ❌ | ✅ |
